# 📚북적북적📚

![image](https://github.com/user-attachments/assets/30c2798e-ce47-4b9a-a0be-c924283f3920)

### 독서를 기록하고, 공유하는 독서 커뮤니티 플랫폼, 북적북적
- 독서 다이어리를 작성하고, 관심사에 맞는 북클럽을 개설하거나 참여하며, 자유롭게 의견을 나누는 게시판 활동을 통해 다른 독자들과 소통할 수 있습니다.
- 알라딘 오픈 API를 활용해 실시간 베스트셀러, 연관 도서, 도서 검색 기능을 제공하여 사용자들이 다양한 책 정보를 손쉽게 확인하고 공유할 수 있도록 지원합니다
<br>

## 🖥️ 프로젝트 개요
### 개발 기간
2025.05.30 ~ 2025.06.19

### 서비스 목적
독서 다이어리를 통해 나의 독서 기록을 남기고, 다른 사람의 독서 다이어리와 자유 게시판을 통해 다양한 사람들과 소통하고, 북클럽 활동을 통해 사람들과 연결될 수 있는 커뮤니티를 제공합니다.

### 타켓 사용자
- 나의 독서 기록을 남기고 싶은 사용자
- 내가 읽은 책에 대하여 다른 사람들과 의견을 나누고 싶은 사용자
- 다른 사람들과 함께 모임을 만들어 독서를 하고 싶은 사용자

### 주요 기능
#### 1. 독서 다이어리
- 나의 독서 기록 작성
- 다른 유저의 독서 다이어리를 열람하여 동일 도서에 대한 다양한 의견 열람
- 댓글, 대댓글, 좋아요을 통해 다른 사용자와 소통

#### 2. 자유 게시판
- 독서 이외의 게시글 작성
- 댓글, 대댓글, 좋아요을 통해 다른 사용자와 소통

#### 3. 북클럽
- 원하는 주제로 활동하는 독서 모임
- 승인된 유저들과 사용 가능한 단체 채팅방 제공

#### 4. 도서 상세 페이지
- 자세히 보고 싶은 도서의 상세한 정보 제공
- 한줄 리뷰를 통해 도서에 대한 다른 사용자의 후기 공유 & 평균 별점 제공
- 도서와 관련있는 다른 도서 목록 제공
- 도서에 대해 작성된 독서 다이어리 목록 제공
- 북마크를 통해 마음에 드는 도서 저장

#### 5. 메인 페이지
- 여러 게시판의 인기글과 베스트셀러 도서를 한 눈에 볼 수 있도록 구성

#### 6. 로그인 • 회원가입
- 자체 회원가입 뿐만 아니라 사용 중인 소셜 계정으로 회원가입 및 로그인 가능

#### 7. 알라딘 API 지원
- 알라딘 API 연결을 통해 도서의 상세 정보 등을 제공
- 알라딘 API를 통해 독서 다이어리 작성 시 대상 도서를 도서 검색으로 선택 가능

### 기대 효과
- 자유롭게 작성하는 독서 다이어리 ➡ 쌓여가는 독서 기록을 통해 독서에 대한 지속적 관심 유도
- 게시판을 통한 다른 유저와의 소통 ➡ 단순 독서 기록 외에도 다른 유저와의 소통의 장을 마련하여 지속적인 커뮤니티 방문 유도
- 북클럽을 통한 모임 생성 ➡ 독서 모임을 위한 공간을 제공하여 단순 게시글을 통한 소통 이상의 독서 활동 진행 가능
